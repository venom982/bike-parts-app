Backup & restore

Your records stay on this device until you export them. An exported backup contains your stock, sales and expenses. Store it privately.

Export backup

Download a JSON backup file, then upload it to Google Drive.

Restore backup

Choose a backup JSON file. Restoring replaces the current records on this device. Export the current data first if you need to keep it.

Save a copy to Google Drive

  1. Download the backup file above.
  2. Open Google Drive.
  3. Tap +, then Upload, and select the downloaded JSON file.

This is a manual backup, not automatic cloud sync. Keep backups private because they may contain business records.
